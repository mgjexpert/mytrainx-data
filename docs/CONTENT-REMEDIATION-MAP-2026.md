# MyTrainX Content Remediation Map — 2026

**Date:** 2026-09-26
**Status:** ACTIVE
**Purpose:** turn the available Drive/PLR/reference archive into a modern MyTrainX editorial pipeline without copying outdated claims or unauthorized third-party content.

## Core rule

The source archive is raw editorial input. It is not the finished MyTrainX library.

Every source is routed through:

SOURCE -> RIGHTS -> EVIDENCE/RISK -> EDITORIAL DECISION -> ORIGINAL MYTRAINX OUTPUT -> REVIEW -> PUBLISH / INDEX

A good old course can inspire a taxonomy, program structure or content gap. It does not automatically become a MyTrainX product.

## Decision codes

- **ADAPT** — rights support transformation and material remains useful after modernization.
- **REBUILD** — concept is useful, but MyTrainX should create an original program/article/course.
- **REFERENCE** — internal research only until rights are proven.
- **QUARANTINE** — medical, unsafe, outdated or rights-sensitive; excluded from normal publication and Coach X retrieval.
- **RETIRE** — low-value, misleading or off-scope.

## 2026 modernization checklist

Before publication:
- replace miracle/absolute claims;
- update exercise programming to current evidence;
- distinguish association from causation;
- remove universal meal prescriptions;
- add practical alternatives;
- add accessibility/regression options;
- record evidence date;
- record rights;
- record reviewer;
- add MyTrainX visual/editorial system;
- generate web-first version;
- generate branded PDF only when rights allow;
- set AI retrieval policy.

## Definition of "MyTrainX original"

An output qualifies as MyTrainX original when its structure and prose were independently produced under the MyTrainX editorial system, it has traceable evidence and rights metadata, and it does not reproduce protected third-party text/media beyond legally permitted use.

MyTrainX branding and watermark are applied only after this gate.
