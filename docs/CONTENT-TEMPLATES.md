## Exercise page

- PT-BR name
- English canonical alias
- goal
- difficulty
- equipment
- primary muscles
- secondary muscles
- movement pattern
- start position
- execution steps
- breathing cue where relevant
- 2–4 coaching cues
- common mistakes
- regressions
- progressions
- alternatives
- safety notes
- video/image
- source/review/version

## Recipe page

- title
- image
- servings
- prep/cook time
- ingredients in normalized weights
- method
- substitutions
- allergens/notes
- storage
- estimated nutrition from canonical source
- recipe tags
- version/review

## Video script

### 0–5s
Title + purpose.

### 5–20s
What the user is about to do/learn.

### Main
One instruction at a time. Avoid simultaneous competing cues.

### Close
One next action.

### Metadata
- exercise/content IDs;
- chapter markers;
- caption language;
- reviewer;
- watermark policy.

## Downloadable PDF

Every page:
- document content ID/version;
- MyTrainX footer watermark;
- page number;
- source attribution when required.

Cover:
- MyTrainX title system;
