# MyTrainX Content Gap Map — 2026-09-25

## Executive view

The current source library is already strong in workout video quantity and legacy program structures. It is weak in canonical normalization, original MyTrainX authorship, modern evidence review, searchable exercise metadata, structured recipes, accessibility, localization, and cohesive visual production.

The priority is therefore not "collect more random courses". It is to convert what is useful into a coherent owned system and fill missing canonical layers.

## Media gap

Current archive contains many third-party videos but MyTrainX-owned media coverage is minimal.

Owned production target:
- 100 highest-use exercise demonstrations first;
- then top 250;
- then full canonical exercise coverage;
- exercise family photo system;
- recipe hero images;
- short educational motion graphics;
- consistent coach intros only when useful.

## Commercial gap

The archive contains potentially transformable PLR but commercial packaging is inconsistent.

Product factory should produce:
- one-time ebooks;
- compact challenges;
- full programs;
- Master-exclusive collections;
- bundles;
- program companion guides.

All transformed PLR must pass rights and originality gates.

## AI knowledge gap

The AI must not rely on raw course folders.

Needed canonical tools:
- search exercises;
- get exercise;
- get progression/regression;
- search library;
- search recipes;
- get recipe;
- get nutrition concept;
- get program material;
- verify entitlement;
- cite evidence/provenance internally.

## Launch definition of "complete"

The Library does not need every possible topic to launch.

V1 complete means:
- coherent IA;
- exercise seed imported;
- top exercise records reviewed;
- foundational training/nutrition content;
- starter recipe collection;
- WKT resources normalized;
- search/filter;
- member state;
- entitlement enforcement;
- rights/review governance;
- Coach X retrieval from approved content.

After launch, completeness becomes an ongoing editorial program.
