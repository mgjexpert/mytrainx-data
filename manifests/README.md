# Manifests

Versioned, non-secret metadata inventories used to reproduce MyTrainX content ingestion.

- `sources/` — source collections and external inventories.
- `library/` — normalized content-item manifests.
- `recipes/` — structured recipe imports.
- `wkt/` — WKT support manifests.

A manifest is not proof of publication rights. Rights and review state travel with every source/content record.
